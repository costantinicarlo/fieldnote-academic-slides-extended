# Fieldnote Academic v0.2.0

Fieldnote Academic v0.2.0 extends the minimalist academic slide system with two complementary closing-slide archetypes.

## Added

- **Acknowledgments slide** for live presentations, with adaptive photographic mosaics, contributor text, financial-support information, and institutional/funder logo walls.
- **Selected references slide** for online presentations, with compact bibliography layouts and clearly styled clickable DOI links.
- Optional templates for both new archetypes.
- Expanded starter deck, pattern library, smoke-test deck, and visual previews.

## Design intent

A live presentation can stop naturally on acknowledgments while questions are discussed. An online slideshow can continue one step further to selected references, allowing readers to follow DOI links directly.

## Compatibility

This release includes the v0.1.1 rendering fix for Slides Extended/Reveal.js section clipping and slide-state display handling.
